Client-side encryption protects content, not every operational event.

RonikCloud still processes object sizes, upload times, opaque file and folder references, access relationships, storage routing, subscription state, and limited security records. Infrastructure can observe connection data, timing, and traffic volume.

The practical question is not “is it encrypted?” but “which data is encrypted, where are the keys used, what remains visible, and how can I recover?”

Google Drive encryption alternative FAQ

Is RonikCloud affiliated with Google Drive?

No. Google Drive is a third-party product. RonikCloud is an independent service and is not affiliated with or endorsed by Google.

Does RonikCloud encrypt file names before storage?

RonikCloud encrypts protected file names and new folder labels on the device, along with protected file content. Older or compatibility records can have different handling until they are migrated or updated.

Does client-side encryption hide all metadata from RonikCloud?

No. The service still needs operational metadata such as object sizes, upload times, opaque identifiers, access relationships, storage routing, subscription state, and limited security records. Network activity also remains observable to service infrastructure.

Can RonikCloud automatically import my Google Drive?

RonikCloud does not currently claim an automatic Google Drive importer. A cautious migration is to export or download files you control, verify the local copy, and then upload selected material through RonikCloud’s protected workflow.
