A practical workspace with clear privacy boundaries.

RonikCloud is a cloud-storage and file-collaboration application with client-side protection for supported content and private workspace labels. It brings storage, sharing, file requests, backup workflows, and collaboration into one workspace.

The current client encrypts protected file content, file names, and new folder labels on the device before storage. HTTPS protects app and browser traffic in transit.

Important boundary: Client-side encryption does not hide all operational information. The service still processes metadata required for storage, routing, authorization, billing, and security operations. This is not a claim of certification or an independent security audit.

Questions, answered plainly.

What is RonikCloud?

RonikCloud is a cloud-storage and file-collaboration application with client-side protection for supported content and private workspace labels. It supports storage, sharing, file requests, backup workflows, and collaboration.

What does RonikCloud protect before upload?

The current client encrypts protected file content, file names, and new folder labels on the device before storage. HTTPS also protects app and browser traffic in transit. Operational metadata is still needed to run the service.

Which RonikCloud releases are available now?

RonikCloud is in a founding beta. Android, iOS, and macOS beta releases are currently published. Windows and Linux builds are not currently available. Visit current downloads for live availability.

Is RonikCloud formally certified or independently audited?

This kit describes the current implementation. It does not claim formal certification or an independent security audit, and RonikCloud should not be described as zero-knowledge or metadata-free.
